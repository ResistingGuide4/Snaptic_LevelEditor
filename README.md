# Snaptic_SM64

This is a mod for the Snaptic Demo made for [GDPatch Modloader](https://gdpatch.dev/)

Adds a Level Editor to the Snaptic Demo as a custom level. You can access it by opening the Dev Terminal (ctrl + alt + d, f1) and typing "level level_editor"

Make sure you have [SnapticBase](https://github.com/xNasuni/SnapticBase) installed along with this mod

Join the [SNAPTIC Modding](https://discord.gg/PgfbejJ8D) discord server for an installation guide!
